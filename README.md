# Komorebi — The Lantern Garden

[Play the Japanese learning village](https://earthyli.github.io/komorebi-lantern-garden/)

Walk to a lantern-lit café and practise everyday Japanese with Haru. Three missions cover listening, ordering and a café conversation. Your notebook, stamps and progress stay in your browser.

Click or tap to walk, use the arrow keys or WASD, or use the on-screen controls. Approach Haru or the café and press E to interact. The Lantern Hours button controls the original garden soundtrack. Spoken Japanese uses a Japanese voice on the visitor’s device when available. Reading help is available in the lessons.

## Development

Run `npm run dev` with Python 3 installed. Run `npm test` and `npm run check` with Node.js. GitHub Pages serves the static site from the `docs` folder of the main branch. Garden art and music are included. The optional score rendering script uses Python and NumPy.
